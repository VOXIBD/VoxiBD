# Código de Conducta – VoxiBD

## 1. Nuestro compromiso

El proyecto VoxiBD busca mantener un entorno de desarrollo respetuoso, colaborativo y profesional, donde todas las personas puedan participar y aportar conocimientos.

## 2. Comportamientos esperados

Todos los participantes deberán:

- Respetar a los demás colaboradores.
- Mantener una comunicación clara y respetuosa.
- Aceptar críticas constructivas.
- Compartir conocimientos y ayudar al equipo.
- Respetar las decisiones técnicas acordadas por el equipo.
- Mantener una actitud profesional durante el desarrollo.

## 3. Comportamientos no permitidos

No se permitirán:

- Insultos, amenazas o faltas de respeto.
- Acoso o discriminación.
- Sabotear intencionadamente el trabajo de otros colaboradores.
- Compartir información privada sin autorización.
- Presentar como propio el trabajo realizado por otras personas.

## 4. Colaboración técnica

Las contribuciones al proyecto deberán respetar las normas de desarrollo establecidas.

Se deberá procurar que el código sea comprensible, mantenible y esté correctamente documentado.

Los cambios importantes deberán comunicarse al resto del equipo.

## 5. Resolución de conflictos

Cualquier problema relacionado con el incumplimiento de este código deberá comunicarse a los responsables del proyecto.

Los responsables evaluarán cada situación y tomarán las medidas necesarias.

## 6. Aplicación

Este código de conducta se aplica a todos los colaboradores de VoxiBD, independientemente de su función o nivel de participación.

Todos los participantes deberán respetar estas normas durante el desarrollo y mantenimiento del proyecto.
